## ESP-IDF managed components

ESP-IDF's component manager downloads the `espressif/mdns` component
according to `main/idf_component.yml`. The generated `managed_components/`
directory is ignored by Git and is not part of this repository. Each
downloaded component retains the license and notices shipped by its
respective author.

Release firmware binaries combine ScopeBuddy code with vendor and managed
components. Each component retains its own license status; the ScopeBuddy
Community License does not replace third-party terms.
